# Bird ID Audio Flashcards

A React-based audio flashcard app for learning West Coast bird vocalizations.

## Features

- 85+ West Coast bird species
- Audio playback for bird calls
- Confidence flagging system
- Multiple sorting and filtering options
- Accuracy tracking
- Life list highlighting

## Getting Started

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Deploy

This app is optimized for deployment on Vercel.

```bash
vercel
```
